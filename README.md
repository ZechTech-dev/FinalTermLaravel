# iBHIMS
### Information-Based Hospital Information Management System

iBHIMS is a web-based Hospital Information Management System developed to support hospital information management and administrative operations. It uses role-based access control to help ensure that users can access features according to their assigned permissions.

## Features

- **Role-Based Access Control (RBAC)** — Controls access to system features based on user roles.
- **Employee Management** — Allows authorized administrators to manage employee records.
- **Landing Page Management** — Allows authorized users to manage landing page photos.
- **User Management** — Supports account administration according to assigned permissions.

## User Roles

| Role | Responsibilities |
|:---|:---|
| **Superadmin** | Manages superadmin accounts and landing page photos. |
| **Admin** | Manages employee records and authorized administrative functions. |

## Technologies Used

- Laravel
- PHP
- MySQL
- JavaScript
- HTML and CSS
- Vite
